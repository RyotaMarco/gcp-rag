# Documentation provenance

The production corpus contains excerpts collected from the official Google Cloud
documentation URLs listed in `manifest.json`. Google and the individual page
contributors retain their respective rights. Documentation is attributed to
those original pages, with collection dates and checksums preserved.

Unless otherwise stated on the source page, Google documentation text is licensed
under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) and code samples
under [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0).
See [Google Developers site policies](https://developers.google.com/terms/site-policies).
Extraction removes navigation and splits article bodies into overlapping excerpts;
these excerpts are not a complete copy of the documentation and may become stale.

The hand-written `evaluation/corpus` fixtures are never ingested into this corpus.
